## 一、设计变量

### 颜色
| 变量 | 值 | 用途 |
|------|-----|------|
| `--wall` | `#F0ECE2` | 页面底色（暖纸） |
| `--ink` | `#1B1813` | 主文字 |
| `--mute` | `#6E685C` | 次级文字 |
| `--line` | `#DFD7C7` | 分隔线 |
| `--red` | `#A8332A` | 点缀（在读标记、进度条、聚焦描边） |
| `--rail-bg` | `#161412` | 侧栏/底部 tabbar 底色 |
| `--rail-text` | `rgba(244,236,220,.62)` | 侧栏非激活文字 |
| `--rail-text-on` | `#F7EFDF` | 侧栏激活文字 |

### 字体
| 变量 | 值 | 用途 |
|------|-----|------|
| `--serif` | `"Songti SC","Noto Serif CJK SC","Source Han Serif SC",serif` | 标题、书名、墙注数字 |
| `--sans` | `"PingFang SC","Noto Sans CJK SC","Microsoft YaHei",sans-serif` | 正文、导航、说明 |
| `--mono` | `"SFMono-Regular",Menlo,Consolas,monospace` | 技术型封面（mr-two-chapters、curl-test） |

### 字号阶梯（七档）
| 档位 | 值 | 用途 |
|------|-----|------|
| 11 | `11px` | 编号、快捷键、次级标签 |
| 12 | `12px` | 搜索占位、状态、说明 |
| 13 | `13px` | 封面书名（小）、目录作者 |
| 15 | `15px` | 封面书名（大）、在读标题 |
| 16 | `16px` | 封面书名（中） |
| 22 | `22px` | 封面书名（特大，仅 cv1） |
| 28 | `28px` | 墙注数字（手机） |
| 32 | `32px` | 页面标题 h1 |
| 36 | `36px` | 页面标题 h1（桌面） |

### 间距
- 基础单位：`4px`，所有间距为 4 的倍数。
- 侧栏宽度：桌面 `64px`（图标轨），手机无侧栏。
- 主区 padding：桌面 `0 32px 0 36px`，手机 `0 20px`。
- 封面网格 gap：桌面错落布局无固定 gap，手机 `20px 16px`。

### 圆角与阴影
- 封面圆角：`1px`（桌面）/ `2px`（手机）。
- 封面阴影：`0 18px 30px -18px rgba(35,26,16,.5), 0 2px 4px rgba(35,26,16,.12)`（桌面）；`0 12px 24px -12px rgba(35,26,16,.5), 0 2px 4px rgba(35,26,16,.12)`（手机）。
- 悬停阴影：`0 26px 38px -20px rgba(35,26,16,.55), 0 3px 6px rgba(35,26,16,.14)`。

## 二、组件与状态

### 2.1 封面组件（8 种程序化封面）
| 类名 | 风格 | 尺寸（桌面） | 尺寸（手机） |
|------|------|-------------|-------------|
| `.cv1` | 暖纸 + 朱印 + 山影 | 270×360 | 170×240 |
| `.cv2` | 深蓝 + 月亮 + 竖排标题 | 180×240 | 170×200 |
| `.cv3` | 赭石 + 横排标题 + 英文副题 | 150×200 | 170×180 |
| `.cv4` | 深红 + 细框 + 竖排标题 | 190×250 | 170×200 |
| `.cv5` | 浅蓝 + 圆点 + 横排标题 | 140×180 | 170×160 |
| `.cv6` | 米黄 + 星标 + 外文标题 | 140×185 | 170×170 |
| `.cv7` | 墨绿 + 等宽字体 + 横线 | 160×210 | 170×180 |
| `.cv8` | 深紫 + 等宽字体 + 光标 | 150×200 | 170×170 |

**规则**：封面全部 CSS 绘制，无外链图；文字留在 DOM；封面代理失败时回退到对应程序化封面。

### 2.2 布局状态
| 状态 | 桌面 | 手机 |
|------|------|------|
| **8 本（默认）** | 沙龙式错落布局（绝对定位，1152×590 画布） | 2 列规则网格 |
| **48 本** | 6 列规则网格 | 2 列规则网格 |
| **空书架** | 空展签（见 2.4） | 空展签（见 2.4） |

### 2.3 交互状态
| 状态 | 表现 |
|------|------|
| **默认** | 封面静止，阴影如 2.1 |
| **悬停（桌面）** | `transform: translateY(-7px)`，阴影加深 |
| **按压（手机）** | `transform: scale(.97)`，阴影减弱 |
| **聚焦** | `outline: 2px solid var(--red); outline-offset: 3px` |
| **加载** | 封面淡入 200ms |
| **reduced-motion** | 所有过渡/动画关闭 |

### 2.4 空展签
- 居中小卡片，宽 `280px`，padding `32px 24px`。
- 标题「书架还空着」（serif，22px）。
- 按钮「去导入」（朱红底白字，高 40px，圆角 4px）。
- 下方小字「支持 TXT / 书源补查」（mute，12px）。
- 不画假书、不画占位封面。

## 三、断点

| 断点 | 行为 |
|------|------|
| `≥1280px` | 桌面沙龙式布局，64px 图标轨 |
| `1100–1279px` | 桌面布局，`transform: scale(.92)` 适配 |
| `820–1099px` | 同 1100–1279px |
| `<820px` | 手机布局：无侧栏，2 列网格，底部 tabbar |

## 四、验收点

### 视觉
- [ ] 1280×800 一屏放下，无滚动。
- [ ] 390×844 可滚动，底部 tabbar 不压内容。
- [ ] 无文字溢出、无截断、无重叠。
- [ ] 对比度 ≥4.5:1（正文/背景）。
- [ ] 点击区 ≥24×24px。

### 功能
- [ ] 8 本时桌面为沙龙式错落布局。
- [ ] 48 本时桌面为 6 列规则网格。
- [ ] 空书架显示空展签，可点击「去导入」。
- [ ] 封面悬停/按压/聚焦反馈正确。
- [ ] 封面加载淡入 200ms。
- [ ] `prefers-reduced-motion` 时所有动效关闭。
- [ ] 封面代理失败时回退到程序化封面。

### 代码
- [ ] 书架为 2D DOM，无 WebGL context。
- [ ] 书为 `<a>` 或 `<button>`，键盘可达。
- [ ] 文字留在 DOM，读屏可读。
- [ ] 不引外链图片。

## 五、对 `client.js` 的改动范围

### 移除
- S5 玻璃皮相关样式（`.mr-shelf-grid`、玻璃卡、backdrop-filter）。
- GlassCanvas WebGL 背景（`client.js:172` 附近着色器、`src/components/GlassCanvas.tsx`）。
- 封面/书目切换（G2 已否）。

### 新增
- D-B 展厅样式变量（颜色、字体、字号、间距、圆角、阴影）。
- 8 种程序化封面组件（cv1–cv8）。
- 沙龙式布局（桌面，绝对定位，1152×590 画布）。
- 规则网格布局（48 本时桌面 6 列、手机 2 列）。
- 空展签组件。
- 底部 tabbar（手机）。
- 封面淡入动画（200ms）。
- 悬停/按压/聚焦反馈。

### 保留
- 搜索（⌘K）。
- 书架头（标题、本机书库、按最近翻阅）。
- 离线可用状态。
- 本周阅读时长（侧栏/底部）。

### 冲突裁决
- ADR-0004「书架无 WebGL」：当前 S5 的 GlassCanvas 背景移除，恢复 ADR-0004 的 2D DOM 书架。
- 封面代理 2MiB：保留，失败时回退到程序化封面。
- 最多 48 本：保留，48 本时切换为规则网格。

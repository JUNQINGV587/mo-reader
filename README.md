# 墨读

在 DSH 中复刻「阅读」(Legado) 的阅读插件：书源、订阅、本地书、漫画/音频/视频、阅读页与书源编辑器。

> 状态：M6 完成（2026-11-27）。已交付书源与订阅、本地 TXT/EPUB/PDF/MOBI/AZW/AZW3 导入、书架书目迁移、自定义字体与阅读主题、漫画/音频/视频、TXT/EPUB/PDF 导出、笔记/替换/朗读、阅读统计与「我的」页、整包与轻量备份导出、备份导入的预览与合并、WebDAV 备份上传与取回。计划见《202611-墨读复刻阅读：设计与实施计划》。

## PDF 原版阅读

本地导入的 PDF 默认按原页面渲染（翻页、跳页、50%–300% 缩放、适应宽度），阅读页与详情页都能一键切到文本模式；两种进度分别保存，互不覆盖。原版模式不生成文字层，选词、搜索与笔记请切到文本模式。

PDF 原版渲染使用 pdfjs-dist。宿主只加载打包后的 `dist/client/client.js`，因此 PDF worker 以内联方式打进同一个 bundle。cmaps 与标准字体取自安装的 pdfjs-dist，由本地服务按 `/reader/pdfjs/` 提供（与导入路径同一套资源，不走 CDN），未嵌入字形的中文 PDF 也能正常显示；内联 worker 是 data: URL，资源必须由主线程加载（`useWorkerFetch: false`），交给 worker 的只是解析结果。

## 阅读统计与「我的」

阅读页可见且窗口聚焦时按秒累计，按本地日期分桶、按书聚合；离开阅读页或切到后台立即落盘，重开 DSH 后仍在。顶栏「我的」给出今日、累计、近 7 天与按书排行；清空统计只清时长，不动书架进度与书签。

## 备份与 WebDAV

整包备份是一个 zip：`manifest.json` 记录格式版本与各类条数，其余按「阅读」的备份文件名放书目、书源、分组、书签、笔记、进度、阅读设置、主题、替换规则、字典规则、订阅与封面（`covers/`）；也可以只导出书目与进度。备份不含章节正文、媒体缓存与字体。导入先解压校验并预览新增/更新/跳过，确认后才写库，失败整体回滚；旧的书架 JSON 也能导入。WebDAV 只做上传与取回，配置保存在本机，密码不外发，私网地址需先打开「允许私网」。

## 结构

```text
src/
  core/     与平台无关的核心（数据模型、规则引擎、解析、网络、备份）
  server/   DSH 适配层（Remote、存储、抓取代理、任务）
  web/      Vue 3 界面与 DSH 槽位桥接
test/       构建产物冒烟测试（node --test）
```

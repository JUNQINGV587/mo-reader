# 墨读

墨读是一个在 DSH 里使用的阅读插件。它把文字、漫画、音频、视频和网站入口放进分类书架，阅读进度、笔记和设置都保存在本机；媒体文件按需缓存到 DSH 服务端。

书源规则支持 CSS、JSONPath、XPath 和受限 JavaScript 沙箱；媒体播放和下载走后端代理，HLS 支持标准 AES-128 离线缓存。

## 功能

- 书架按小说、漫画、音频、视频、网页、订阅分栏，各有独立入口
- 书架、发现、目录和阅读进度；漫画、音频、视频可在对应阅读器播放/看图
- 导入 JSON 书源、订阅公开源库；支持 Legado 文本/音频/漫画/视频书源和网站源
- 导入 Legado 订阅源 JSON 或标准 RSS 2.0 feed；订阅按分类或 feed 生成作品
- 书源规则支持 CSS、JSONPath、XPath、JSON POST 和受限 JavaScript 沙箱
- 导入 TXT、EPUB，本地书籍也能整本下载
- 媒体下载面板：章节复选、暂停/继续/重试、取消单章、容量与保留标记
- 漫画默认纵向滚动，可按书切换翻页；音频离开阅读页后由底部迷你条继续播放
- 默认上下滚动；也可切到翻页，选滑动/翻转/淡入三式；窄屏单栏，宽屏双栏；点按/键盘/拖拽滑动翻页，章末跨章并浮现章节名
- 动画设置：默认阅读方式、默认翻页、动画开关、画质、氛围、减弱动态；每本书可单独覆盖阅读方式、翻页和氛围
- 进度按字符位置保存，改字号或换分栏后回到同一段文字
- 无 WebGL 或减少动态时自动降级：阅读页静态文字可读、翻页瞬时；书架是 2D，不依赖 WebGL
- 字号、行距、主题、系统听书、替换净化和选文笔记
- DSH 运行时每小时检查书源订阅与书架更新，重新打开后补查
- 本机持久化和备份恢复，备份包含非敏感订阅元数据，不包含媒体缓存、密码、Cookie 或令牌
- 响应式封面书架：手机三列，桌面按宽高自适应；长按多选，书是键盘/读屏可用的按钮
- 桌面与手机布局

## 安装

需要 DSH 0.2.2-alpha.3，以及 Node.js 24.9.0 或更高版本。

阅读页氛围在 `client.gl.js`（原生 WebGL，手写、无构建）；改完直接刷新插件即可。

```bash
git clone https://github.com/JUNQINGV587/mo-reader.git
cd mo-reader
npm ci --ignore-scripts
```

在 DSH 的插件管理中安装这个目录。安装后如果提示重启，重启 DSH，再从左侧「墨读」进入。

本项目保留 `private: true`，目前只作为本地 DSH bundle 分发，不发布到 npm。

## 书源与本地书籍

「书源」页面支持粘贴 JSON、导入 JSON 文件，或订阅一个公开的**书源库**地址。订阅、来源关系和启停状态保存在本机，重新打开后继续使用。源库订阅是书源合集，不接受 Legado 的 RSS 订阅源。

Legado 的**订阅源** JSON（`sourceName/sourceUrl/ruleArticles` 这类）也从同一入口导入：墨读会列出源里声明的分类，勾选后每个分类在书架「订阅」区生成一张作品卡。订阅源只保存源地址与分类信息；Cookie、登录信息和注入脚本不落库，导入时会明确标为不支持。

标准 **RSS 2.0** feed 可以直接贴地址导入：一个 feed 一部订阅，条目按发布时间倒序（没有发布时间的条目保持 feed 原序）；只有摘要的 feed 也能读。没有摘要/正文的条目会被跳过。Atom 暂不支持，导入时会明确报错。

订阅条目按图文块渲染（标题、引用、代码、列表、图片），图片经媒体代理加载并缓存；正文里的脚本和 iframe 不会执行或渲染。

书源规则支持：

- CSS 选择器与 JSONPath；XPath 支持常见元素、属性、索引、文本和 `contains()` 子集，超出子集会明确报错
- GET 与 POST；POST 支持表单和 JSON 请求体
- Legado `@js` 字段规则，在独立 Worker 的受限沙箱中运行；只能访问同源网络，不能读取 DSH 凭据、本地文件或其他书源数据

不支持登录、验证码、付费和内置 WebView 书源；这类源会在列表中标记，并在请求前明确失败。

订阅在 DSH 运行时每小时检查，重新打开后补查。更新会先完整获取、解析和校验候选源库，再原子替换；获取或校验失败时保留旧版并记录失败。候选新增网站或新增 JavaScript/HTTP/POST 能力时会进入「待确认」，旧版继续可用；确认只应用这次已获取的候选，拒绝则继续使用旧版。上游删除的书源只在没有其他订阅使用时移除，书架书籍和已下载章节保留。

TXT 和 EPUB 可以从「设置」页面导入。EPUB 当前只导入正文，不导入图片。

## 媒体与网页

Legado `bookSourceType` 0/1/2/4 分别对应小说、音频、漫画、视频；类型 3（网络文件）会明确报不支持。网站源使用扩展 JSON：`contentType: "website"`、`homeUrl`、可选 `searchUrl`（`{{key}}` 为搜索词）。网站源只作为站点入口，点击后用外部浏览器打开，不在插件内嵌 iframe，也不读取或保存浏览器 Cookie。

媒体默认在线播放/看图。播放和分片请求由墨读后端代理，带书源声明的 Referer/请求头；漫画图片、音频、视频和 HLS 都优先使用本地缓存。下载按作品进行，可取消单章、暂停、继续和重试；HLS 会保存最高可用码率、AES-128 解密后的分片和本地 playlist，不保存 key。

媒体缓存默认位于 `~/.dsh/reader/media`，配额默认 50GB，可在设置中调整。空间不足时按整部作品淘汰最久未访问的缓存；标记保留或正在下载的作品不会淘汰。媒体文件、HLS 索引、Cookie 和密钥不进入备份，作品、章节和进度会随备份恢复。

不支持 Widevine/FairPlay/SAMPLE-AES 等 DRM，也不支持需要浏览器登录 Cookie 才能拉取的媒体；遇到时会给出明确错误。在线 HLS 的短期签名与当前进程绑定，DSH 重启后需要重新打开章节。

请只使用自己有权访问的内容。插件不绕过登录、付费、验证码或反爬限制，也不会在 DSH 关闭后常驻追更。

## 开发

```bash
npm ci --ignore-scripts
npm test
```

测试不访问网络，覆盖书源规则、TXT/EPUB、四类媒体载荷与下载、网站源、媒体代理与配额、阅读进度与每本阅读偏好、书架排版、滚动动效纯函数、笔记、备份和真实持久化后端。GitHub Actions 会在 Node.js 24.9.0 和最新 24.x 上运行测试。

## 隐私

书源搜索、正文/媒体下载和追更会访问你配置的网站。媒体文件默认缓存在 DSH 服务端的 `~/.dsh/reader/media`，不会上传到其他位置；其余阅读数据默认留在本机。HTTP 书源需要单独允许，备份会剔除常见凭据字段和媒体缓存。
